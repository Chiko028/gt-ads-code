# ADR-0004: PostgreSQL und pg-boss (Queue)

Status: Vorgeschlagen – wartet auf Freigabe durch den Betreiber
Datum: 2026-11-09
Quelle: ARCHITEKTUR §2, §14 (ADR-02); Annahme A-13

## Kontext
Relationale Daten, Partitionierung, wenig Betriebsdienste.

## Entscheidung
PostgreSQL 17, Jobs per pg-boss; kein Redis.

## Alternativen
Redis/RabbitMQ, ClickHouse.

## Folgen
Ein Dienst weniger; Durchsatz im Lasttest (WP-211) belegen.
