# ADR-0003: Offline-first mit versionierten Manifesten

Status: Akzeptiert – folgt aus Betreiberanforderung (Offline-Wiedergabe, KONZEPT §5)
Datum: 2026-11-09
Quelle: BRIEFING; F-A06, F-A07

## Kontext
Tablets haben unzuverlässiges Mobilfunknetz.

## Entscheidung
Server erzeugt unveränderliche Manifest-Versionen; Tablet lädt vollständig, prüft Hashes, schaltet atomar um und spielt lokal.

## Alternativen
Streaming, Dauerverbindung.

## Folgen
Tablet-Logik komplexer; Server bleibt einfach und skalierbar.

## Änderungen
Nur per neuem ADR (Status „Ersetzt durch ADR-nnnn"); Betreiberfreigabe erforderlich.
