# ADR-0011: Trennung Entwicklungs-/Test-/Produktivdaten

Status: Vorgeschlagen – wartet auf Freigabe durch den Betreiber
Datum: 2026-11-09
Quelle: docs/prozess/DATENTRENNUNG.md

## Kontext
Keine automatischen Testdaten in Produktion; keine Produktivdaten zu KI-APIs.

## Entscheidung
Umgebungs-Guard `GT_ADS_ENV`, synthetische Generatoren, getrennte DBs/Secrets, Prod nicht erreichbar aus dev/test.

## Alternativen
Gemeinsame Datenbank mit Kennzeichnung.

## Folgen
Zusätzliche Tests/Guards; Staging optional später.

## Änderungen
Nur per neuem ADR (Status „Ersetzt durch ADR-nnnn"); Betreiberfreigabe erforderlich.
