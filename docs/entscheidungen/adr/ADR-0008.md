# ADR-0008: KI-Agenten isoliert und rechtearm

Status: Akzeptiert (Grundsatz, Betreiberregeln: keine Root-Agenten, getrennt von Produktion); Ausgestaltung vorgeschlagen
Datum: 2026-11-09
Quelle: SYSTEM-AUFTRAG Sicherheitsregeln; ARCHITEKTUR §9, §14 (ADR-08)

## Kontext
Agenten dürfen Produktivdaten und Root nicht erreichen.

## Entscheidung
Eigener Benutzer `taxiagent`, eigenes Netz, nur API-Tokens mit minimalen Rechten, Schreibaktionen als Entwurf, Freigabepflicht.

## Alternativen
Agenten mit direktem DB-/Shell-Zugriff.

## Folgen
Freigabekonzept je Agent (E34).

## Änderungen
Nur per neuem ADR (Status „Ersetzt durch ADR-nnnn"); Betreiberfreigabe erforderlich.
