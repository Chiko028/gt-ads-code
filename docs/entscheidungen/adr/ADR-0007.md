# ADR-0007: Domain statt IP, Storage-Interface, 12-Factor

Status: Vorgeschlagen – wartet auf Freigabe durch den Betreiber
Datum: 2026-11-09
Quelle: ARCHITEKTUR §11, §14 (ADR-07)

## Kontext
Migration VPS → Dedicated ohne App-Neuauslieferung.

## Entscheidung
Tablets kennen nur Domain; Medien hinter Storage-Interface; Konfiguration per Umgebung.

## Alternativen
Feste IP, Pfade im Code.

## Folgen
Domain nötig (E1).

## Änderungen
Nur per neuem ADR (Status „Ersetzt durch ADR-nnnn"); Betreiberfreigabe erforderlich.
